# Scope of this design paper

Develop a prose-first architectural proposal for a Lean-oriented verified CNC library in which every admitted design carries a manufacturing witness. Define constructibility relative to a process, stock, tools, material, fixturing, machine kinematics, and acceptance specification. Separate mathematical geometry, executable approximations, checked plans, and physical assumptions.

Include a worked toy case, failure cases, theorem targets, an evidence boundary, and a staged research agenda. Discuss Grassmann's public geometric-algebra design as context. Include only modest illustrative type signatures; no CNC implementation, controller commands, fabricated proof results, or order placement.

Record documented SendCutSend file-based workflows and prepare a read-only documentation plugin. Authenticated integration depends on an officially supported interface and separately approved access. This repository contains original prose and public citations, with no imported Grassmann source, private research notes, account data, or credentials.
